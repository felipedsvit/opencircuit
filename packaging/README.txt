OpenCircuit @VERSION@
=====================

An editor and simulator for industrial control circuits.

  opencircuit-desktop [PROJECT.ocircuit]   the window
  opencircuit validate|simulate|test|export|new|edit|serve ...   the command line

Open one of the projects in the examples folder to start, for instance
examples/direct-starter/starter.ocircuit, and press Edit to draw.

This build is not signed. Windows may show SmartScreen ("More info", then
"Run anyway"); macOS asks to confirm the first start (right-click the
application, "Open").
